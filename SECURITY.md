# Seguridad

Nexo Norte es un proyecto demostrativo. Si encuentras una vulnerabilidad, no la publiques en un issue abierto.

## Versiones soportadas

| Versión | Soporte |
| --- | --- |
| Rama `main` | Sí |
| Ramas o versiones anteriores | No |

Reporta el problema de forma privada mediante **Security Advisories** en GitHub e incluye:

- componente afectado;
- pasos mínimos para reproducirlo;
- impacto observado;
- propuesta de mitigación, si la tienes.

No incluyas contraseñas, llaves, datos personales ni información real de clientes en el reporte.

Confirmaremos la recepción en un máximo de tres días hábiles y comunicaremos el plan de mitigación cuando el impacto haya sido validado.

El modelo de amenazas y los controles técnicos están documentados en [`docs/threat-model.md`](docs/threat-model.md).
