Privacidad

Datos mínimos, propósito claro.

Qué recopilamos

Nombre, negocio, país de operación, correo electrónico, necesidad principal y el mensaje que decidas compartir.

Para qué se utilizan

Únicamente para responder la solicitud, mostrar el contexto regional correcto y preparar una conversación inicial sobre el diagnóstico.

Preferencia regional

La página utiliza el idioma y la zona horaria informados por tu navegador para sugerir Colombia o Perú, sin solicitar ubicación GPS ni enviar estos datos a terceros. Tu decisión se guarda localmente para mantener una experiencia consistente.

Cómo se protegen

La aplicación valida cada envío, protege el formulario contra solicitudes cruzadas y restringe el acceso administrativo.

Proyecto demostrativo

Nexo Norte es actualmente un proyecto de portafolio. No envíes información sensible, financiera, médica ni credenciales.
